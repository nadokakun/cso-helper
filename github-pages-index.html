CSO Helper

這裡只保留最新的獨立書籤：Auto PASS、摺疊「已停用主項目」、以及復原摺疊項目。每個功能都可以分開啟用。

Auto PASS

啟用後，點 PASS 時會自動按下 送出並前往下一項，且不主動捲動畫面。

Auto PASS 最新版

摺疊已停用主項目

啟用後，只處理含有 已停用主項目 文字的區塊，不會觸發 Auto PASS。

摺疊已停用主項目 最新版

復原摺疊項目

啟用後，會取消摺疊規則，並把先前被隱藏的 已停用主項目 區塊顯示回來。

復原摺疊項目 最新版
  1. 把需要的按鈕拖到瀏覽器書籤列。
  2. 回到已登入的測試頁面，點書籤啟用。
  3. 三個功能要分開啟用：Auto PASS 只管送出，摺疊只管隱藏區塊，復原只管取消隱藏。
